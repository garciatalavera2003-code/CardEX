Analysis settings · v1.5.0

Novedad: cámara local con detección geométrica, autocaptura estable, recorte por perspectiva y guardado en este navegador. El detector está incluido en este HTML y funciona sin descargar librerías. OCR y catálogo siguen necesitando internet.

Para probar: Cámara · detectar frontal → permitir cámara → mantener una carta estable → captura automática → comprobar original y recorte → identificación OCR. Si no llega a capturar, pulsa «Tomar foto ahora»; se conserva la fotografía completa cuando no hay contorno confirmado.

Limitación: el detector local reconoce geometría rectangular, no verifica que el objeto sea una carta Pokémon. No recupera detalles que no estén en la foto. Brillos, fundas, fondos rectangulares y desenfoque intenso pueden provocar fallos.

Abrir esta versión en el teléfono / GitHub Pages

Guarda el archivo como index.html en la carpeta publicada por GitHub Pages. En el repositorio abre Settings → Pages, selecciona la rama y carpeta correctas, y espera a que finalice el despliegue en Actions.

Abre la URL de Visit site en Safari o Chrome. La vista del archivo en github.com no ejecuta la aplicación. Comprueba que aparece v1.5.0; si ves una versión antigua, recarga la página o prueba una pestaña privada.

Instrucciones oficiales de GitHub Pages

Estándar activo: PCI Prototype v1 · Escala 1.0–10.0

Identificación: Tesseract.js 6 · OCR local + catálogo TCGdex por idioma. Requiere internet para descargar el motor, idiomas, catálogo e imágenes de referencia. Las fotos no se suben a TCGdex.

Grading: sigue simulado. La coincidencia OCR no es una verificación de autenticidad ni de variante.

Las confianzas son valores de demostración, no probabilidades calibradas. La calificación no equivale a una certificación PSA, BGS o SGC.
